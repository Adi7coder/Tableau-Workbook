Titanic Dataset – Tableau Visualizations

This repository contains Tableau visualizations created from the classic Titanic dataset, exploring survival patterns, demographic distributions, and relationships between features.

🧾 Dataset

The dataset used is the standard Titanic.csv, containing features such as:

Survived

Pclass

Sex

Age

Fare

Embarked

📘 Visualizations Included
1️⃣ Passengers vs. Gender (Bar Chart)

A bar chart representing the number of male and female passengers.

2️⃣ Survival Count by Gender

Stacked bar chart showing how many males and females survived vs. did not survive.

3️⃣ Survival Rate by Passenger Class

Average survival rate segmented by class (1st, 2nd, 3rd).

4️⃣ Age Distribution (Histogram)

A histogram showing how passenger ages are distributed.

5️⃣ Average Fare by Class

Bar chart showing average ticket fare for each class.

6️⃣ Fare vs Age (Scatter Plot)

A scatter plot visualizing the relationship between fare paid and passenger age.

7️⃣ Passenger Count by Embarkation Port

Count of passengers grouped by embarkation location (C, Q, S).

8️⃣ Survival Heatmap (Gender × Class)

Heatmap showing survival intensity across gender and class combinations.

9️⃣ Age vs Survival (Box Plot)

A box-and-whisker plot showing the age spread for survivors vs. non-survivors.

🔟 Pie Chart (Dimension + Measure)

Pie chart representing the proportion of passengers by gender.
